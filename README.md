# Pocket Todos

A playful, polished todo list built with React and Vite.

## Features

- Add, complete, filter, and delete tasks
- Progress tracker and completed-task cleanup
- Local storage, so tasks survive refreshes
- Responsive design for mobile and desktop
- Accessible controls and keyboard-friendly interactions

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
